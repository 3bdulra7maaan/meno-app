# Meno V1.2.1 — approved UI implementation

This release applies the approved Meno concept board to the existing Flutter
application and Admin dashboard without changing Supabase data flows, RLS,
moderation, search, reports, analytics, or authentication.

## Before and after

| Area | V1.2 | V1.2.1 |
| --- | --- | --- |
| App shell | Warm off-white screens and Material navigation | Near-black shell, gold wordmark and custom five-item navigation |
| Home | Search-led hero and light question cards | Banner-led composition, compact dark category tiles and dark question cards |
| Secondary screens | Mostly light surfaces | Consistent black, charcoal, cream and restrained gold surfaces |
| Admin | Functional responsive dashboard | Polished off-white canvas, black sidebar, gold active state and upload dropzone |

## Intentionally preserved differences

- Question sharing continues to use Android's native share sheet instead of
  drawing fake WhatsApp, Facebook, X, or Telegram buttons.
- The bottom navigation keeps the working **أسئلتي** destination in place of a
  fake notifications screen.
- Banner imagery remains controlled by live Supabase content. A branded,
  non-blocking placeholder appears when a remote image cannot load.
- Admin screenshots use representative, non-production values. The shipped
  dashboard continues to load real values only after Supabase Auth and RLS
  authorize the admin.
